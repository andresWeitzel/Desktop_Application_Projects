<div align="center">
  
##  <img width="36" height="48" src="../doc/assets/gifs/desktop.gif" />  Desktop App

</div>

</br>


Central repository for desktop applications that digitize internal organizational operations: records and user administration, billing and operational control, analytical reporting, Swing and Windows Forms GUIs, relational and non-relational persistence, and local and production deployment.
 
<br>

  * Languages: Java, C#, others.
  * Frameworks: Swing, Windows Forms, JavaFX, JDBC, others.
  * Technologies: Java SE, .NET, Maven, others.
  * Databases: MySQL, MariaDB, PostgreSQL, others.
  * Libraries: mysql-connector, JFreeChart, JCommon, ADO.NET, others.
  * Tools: NetBeans, VSC, Git, Postman, XAMPP, DBeaver, Docker, others.
  * Patterns: DAO, Singleton, others.
